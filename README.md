# Azure-ML-Bank-loan-status
Azure ML classification project: automated setup, baseline and AutoML modelling and deployment.

How to deploy model:

1) Set up resource group and compute if needed by running setup.sh found at 'Azure ML bank loan status/AutoML/AutoML 30 trials/setup.sh' in microsft azure
2) clone repo and run model deployment notebook.ipynb found at 'Azure ML bank loan status/AutoML/model deployment notebook.ipynb'
